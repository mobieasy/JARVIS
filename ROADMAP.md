# Roadmap

These are proposed milestones, not implemented feature claims or delivery promises.

1. **Foundation:** reproducible setup, configuration validation, recovery/restore tooling, model selection, measured caching and cost visibility.
2. **Persistent work:** project notes, source-aware recall, durable task states/checkpoints, progress, stop/resume and interrupted-action reconciliation. Persisting a card alone does not automatically resume its execution.
3. **Connected workflows:** repository work, documents/spreadsheets, source-linked research, scoped email and messaging adapters, and a private approval inbox.
4. **Proactivity:** explicit responsibilities, event-driven checks, quiet hours, per-task budgets and meaningful-change alerts. No default recurring paid AI jobs.
5. **Mobile and voice:** accessible mobile web, multilingual push-to-talk, an Android companion, and individually approved device capabilities.
6. **Specialized operations:** optional laptop/browser workers and separately evaluated customer-calling workflows. Provider, device and regulatory requirements need current verification.
7. **Memory and skills maintenance:** revisit background consolidation and skill reviews after write permissions, memory provenance, cost limits, proposal review and scheduling controls are proven. Creative diary text must never become a verified personal fact.

The practical target is a dependable assistant inspired by dots-style continuity and Grok-style timely research. Exact hosted-product parity, unlimited usage and universal phone control are not promised.
